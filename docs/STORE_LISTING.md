## 4. Google Play Data Safety Answers

* **Does your app collect or share user data?** Yes.
* **Data Types Collected:**
  - **Name & Email:** For user account authentication and session synchronization.
  - **App Activity / Interactions:** Lesson completion records, XP, and streak scores to maintain progression.
  - **Audio:** Voice audio processed on device for pronunciation scoring (not stored permanently or shared).
* **Security Practices:**
  - Data encrypted in transit using TLS 1.3 / HTTPS.
  - Full user data deletion supported via in-app button (**Profile > Delete Account**).
